[1. 객체 생성 기준]

차량 객체는 LiDAR Point Cloud에서 객체의 외곽을 기준으로 큐보이드를 생성한다.
객체의 길이, 폭, 높이는 실제 객체의 형태를 최대한 반영해야 한다.

[2. 가림 객체 처리 기준]

다른 객체에 의해 일부가 가려진 차량이라도 동일 객체임을 식별할 수 있고,
가이드의 최소 가시 기준을 충족하면 큐보이드를 생성한다.

객체가 너무 많이 가려져 동일 객체인지 판단하기 어렵거나,
최소 가시 기준을 충족하지 못한 경우에는 PM에게 확인한다.

[3. 큐보이드 방향]

큐보이드의 방향은 차량의 실제 전방 방향을 기준으로 설정한다.
주차된 차량도 차량 자체의 전방 방향을 기준으로 한다.

[4. 포인트가 적은 객체]

LiDAR Point가 적더라도 객체의 형태와 위치를 식별할 수 있으면 작업한다.
객체 식별이 어려운 경우에는 임의로 판단하지 않고 PM에게 문의한다.

[5. 반복 오류]

동일한 오류가 반복되는 작업자는 해당 기준을 다시 안내하고 피드백한다.
여러 작업자가 같은 기준을 다르게 해석하는 경우 가이드를 재확인하고
공통 기준을 정리해 전체 작업자에게 공유한다.
